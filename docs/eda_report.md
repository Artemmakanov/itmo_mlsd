# Приложение: Отчет по Exploratory Data Analysis (EDA)

**Проект:** Guardrails Pre-filter для LLM-агентов

**Задача:** Подготовка данных для обучения классификатора (1 - attack, 0 - benign)

---

## 1. Анализ промптов

В данных было поле adversarial, отвечающее за то, что сам промпт является сложным/простым для классификации.
Поскольку проект является учебным, то для упрощение в итоговую выборку были взяты только простые примеры.

## 3. Краткая сводка выводов по EDA

* **Сложность задачи:** На графике **PCA** видно значительное смешивание классов в центре распределения. Это подтверждает, что простые "счетчики" не справятся с защитой, и использование LLM оправдано.
* **Состав выборки:** Для обучения извлечено 10000 строк. Итого в обучающей выборке 55% атак и 44% доброкачественных промптов. Для теста было взято 10000 строк, распределение по колонкам `label` сохранено эквивалентно трейну, для сохранения адекватности валидации, в eval отошел остаток промптов (3000-4000 строк).
* **Информативность:** Распределение длин слов (**Wordcount**) показывает, что атаки не имеют единого шаблона по длине, что делает их детектирование через простые эвристики затруднительным.
* **Итог:** Сформированный датасет является репрезентативным для "умного" пре-фильтра, так как заставляет модель фокусироваться на скрытых паттернах атак, а не на простых ключевых словах.
