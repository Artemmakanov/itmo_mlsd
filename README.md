## LLM Guardrails with AutoML
Учебный проект в рамках курса “ML Systems Design”
# 📌 Описание проекта
Этот проект — игрушечная демонстрация подхода к построению LLM Guardrails в условиях, когда:
у нас есть небольшая размеченная выборка для текстовой генерации,
мы хотим выявлять вредоносные или приватные атаки в данных,
затем автоматически подбирать стратегии защиты (AutoML),
и проверять устойчивость модели к найденным атакам.
Проект иллюстрирует цикл разработки защит для LLM:
детекция атак → генерация атак → оценка риска → автоматический поиск guardrails → валидация.
# 🎯 Основные цели
Показать, как можно собрать pipeline для LLM guardrails.
Потренироваться в генерации атак и их детекции.
Использовать AutoML для поиска:
атакующих промптов,
правил защиты,
оптимальных конфигураций guardrails.

# ⚙️ Pipeline
